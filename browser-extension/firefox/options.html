Health Records Capture

Sends records you view on your patient portals to your own healthdash dashboard on your home network. It is off until you switch it on from the toolbar button, it only works on the portal sites listed below, and it only sends to the dashboard address below. Nothing goes to anyone else.

Your dashboards

One per person. The popup's Save to picks which one gets what you save. Keys come from each dashboard: 👤 → Accounts → Browser plugin keys → Create a key.

Portal sites

One per line. * matches anything. MyChart runs on each health system's own web address, so the MyChart lines match its /MyChart/ pages on any site. Firefox will ask you to allow the plugin on these sites.
